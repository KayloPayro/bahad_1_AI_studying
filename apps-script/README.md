# חיבור מעקב ההתקדמות (Apps Script)

פעם אחת, מחשבון Google של הסגל. אחרי זה אין שרת לתחזק.

1. פותחים גיליון Google חדש, למשל "מעקב לומדות AI".
2. בתפריט: **Extensions → Apps Script**. מוחקים את מה שיש ומדביקים את כל התוכן של [Code.gs](Code.gs).
3. **Project Settings → Script properties** ומוסיפים:
   - `STAFF_CODE`: הקוד שהסגל יקליד בעמוד המעקב.
   - `PN_LENGTH`: אורך המספר האישי. ברירת המחדל היא 7, וחייב להתאים ל-`PN_LENGTH` בקובץ `site.config.json`.
4. **Deploy → New deployment → Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
5. מאשרים הרשאות ומעתיקים את כתובת ה-Web App (מסתיימת ב-`/exec`).
6. מדביקים אותה ב-`TRACKING_URL` בקובץ [site.config.json](../site.config.json), ובונים ופורסים מחדש.

הגיליון `events` נוצר לבד באירוע הראשון. העמודות הן לפי האפיון: זמן, מספר אישי, צוות, לומדה, אירוע, שלב, ציון, משך, גרסה.

## בדיקה

- פותחים לומדה, נכנסים עם מספר אישי, ולוחצים "התחל". אחרי כמה שניות אמורה להופיע שורה `start` בגיליון.
- עמוד הסגל: `<כתובת האתר>/staff/`, עם הקוד מ-`STAFF_CODE`.

## פרטיות

- נשמרים רק מספר אישי, צוות, לומדה, זמנים וציון. התוצרים שהצוער מדביק נשארים במכשיר שלו.
- הגיליון משותף רק לסגל ונמחק בסוף הקורס.
- **לאמת לפני הפיילוט:** שמותר לשמור מספרים אישיים בחשבון Google אזרחי. אם לא, מחלקים קודי צוער באותו אורך במקום מספר אישי, בלי שינוי בקוד.

## עדכון הסקריפט

אחרי שינוי ב-Code.gs: **Deploy → Manage deployments → Edit → Version: New version**. הכתובת נשארת אותה כתובת.
